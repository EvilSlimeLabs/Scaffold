# Scaffold's dependencies are declared in pyproject.toml, which is where
# PEP 621 says they belong. This file exists so that `pip install -r
# requirements.txt` still does the right thing.
#
#   pip install -e .            the library and the command line
#   pip install -e ".[gui]"     and the desktop window
#   pip install -e ".[dev]"     and everything needed to build a release
#
# tkinter is not installable from PyPI. It ships with CPython on Windows and
# macOS; on Linux it is a system package (python3-tk on Debian and Ubuntu,
# python3-tkinter on Fedora).

-e .[gui]
